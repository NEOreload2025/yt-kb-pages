便宜開源模型 + 免費 harness，能取代付費 coding 工具嗎？

省 10 倍錢的代價
是 15% 可用性

免費的開源 harness 裝上便宜的開源模型（GLM-5.3-Flash），智能只輸旗艦 2 分，價格省近 20 倍——但真正的交易不是比智能，是比「可用性 vs 帳單」。
1

帳面上的價差：近 20 倍

同一家公司、同一系列的兩個版本，價格差近 20 倍——但智能分數只差 2 分。
GLM-5.3-Flash（輕量）GLM-5.3（旗艦）
輸入$0.075/M（促銷）→ $0.15/M$1.40/M
輸出$0.25/M（促銷）→ $0.42/M$4.40/M
智能（agentic）51.5（勝 90% 模型）53.6

影片統計當下（9/7–9/9）：Flash 正在 50% 促銷，9/9 到期回歸原價。即便漲價，跟旗艦仍然差 10–20 倍。而實測成績：純 coding 71.5%（勝 84% 模型）、agent 工作流 51.5（勝 90% 模型）——便宜的不等於弱的。

2

你的帳單其實是「輸入」在付錢

Agent 工作流的 input:output 比是 38:1——輸入價才是整張帳單，輸出價幾乎不動。

OpenRouter 統計 10 天流量：GLM-5.3-Flash 收到 1.25T tokens 輸入，只吐回 32B tokens。原因：harness 每一步都在重讀你的檔案——掃一大段程式碼，只為了寫幾行新 code。

所以輸入單價才是你要盯的數字，而且只有輸入側能靠 cache 壓低：實測買家實付輸入均價 ~$0.0325/M（快取命中率各家 27%–90% 不等）。快取命中 = host 記得你送過的檔案，重讀不收錢。

3

「便宜」不是模型的特質，是供應商的

同一個模型在 OpenRouter 上有 23 家供應商——速度差 28 倍、價格也各不相同。

最快的 host 寫出 168 tokens/s，最慢只有 6 tokens/s。同一顆模型，完全不同體驗。價格同樣如此：有 host 賣促銷價的 5 倍，也有 host 不用促銷就低於牌價。

結論：你實際買到的「便宜」，取決於當天跑它的 host，而不是模型本身。

4

Exacto：為「tool call 掉球」而生

Agent 幹活全靠 tool call——host 如果在這一步掉球，省的錢都是白省。

Tool call = agent 請求「讀檔」或「跑指令」的那一刻。它在，chat box 才變成真正的工具。如果 host 在這步失誤，agent 整個停止。

OpenRouter 對每筆 tool call 檢查三種失敗：InvalidJson（壞 JSON）、UnknownName（幻覺出不存在的工具）、SchemaMismatch（參數結構不對），並替每家 host 公布 Tool Call Error Rate 和 Cache Hit Rate 兩個即時指標。

因為「同一個模型、不同 host 品質差很多」，OpenRouter 做了 Exacto 路由（2025/10）：只路由到 tool-call 準確率頂級的 host。實測 Tau2-Bench / LiveMCPBench 提升 10–20%。

第二代 Auto Exacto（2026/3）：帶 tools 的請求預設自動啟用、每約 5 分鐘重評吞吐/遙測/benchmark 三訊號，把預設路由從「價格優先」改為「品質優先」。官方數據：GLM-5 的 error rate 8% → 1%（-88%）、GLM-4.7 -80%。

给自己的提醒：我們走的是 opencode Go 池（不是 OpenRouter）——Go 池官方說明有先做基準測試篩選 host，相當於做了初步的 Exacto，但不公開 per-host 遙測，透明度較低。x-opencode-session header 就扮演了 Go 池版的 routing/cache key。

5

免費 harness 的真實風險

DeepSeek Harness 是 v0.1.3 alpha，作者全大寫警告 breaking changes。
  • 版本 v0.1.3 alpha.1（pre-release，總共才 11 個 tag），首頁全大寫警告會有 breaking changes
  • 內建 model picker 凍結在編譯時：列表 333 個，市場實際 431 個——社群插件 flykit 改成啟動時拉 live list 就解決了
  • 上架 3 週已有 ~14,000 個插件 repo——「無特權核心」架構，模型適配器、工具列表、甚至 agent loop 都能換
  • 插件換不掉的：底層 harness 的 breaking changes——你的自訂 loop 會跟著一起壞
6

彩蛋：Claude Code 自己也在偷用

OpenRouter 用量榜第二大買家，就是 Claude Code——2.5T tokens。

社群有人寫插件把付費的 Claude Code 訂閱 + 免費 harness 對接——登入憑證寫進同一份 credential 檔。意思很清楚：工具跟模型，不必來自同一家公司。付費訂閱買的安心感，跟省錢的模型，可以拆開買。

7

結論：一筆交易公式

放棄約 15% 可用性，換約 10 倍省錢。適不適用看你的工作模式。
場景用便宜方案？原因
背景任務（過夜跑）✅ 適合掉球重試即可，省的錢是真的
deadline 現場工作❌ 不適合重試的時間成本 > 省的錢

便宜模型的真實短板不是智商（只差 2 分），而是可用性：單一 host 上 84.5% vs 旗艦 97%——每 100 個請求多掉 15 個。付費方案買的其實是「不掉球」的保證。

8

給自己的三條啟示

  1. 成本看輸入側：agent 帳單 38:1 壓在 input，快取命中率決定實付（~$0.0325/M vs 牌價 $0.15）。
  2. 供應商 > 模型：同一模型 23 家 host，速度差 28 倍、「便宜」歸 host；tool call error rate 才是掉球元兇。
  3. 架構比訂閱重要：「工具 vs 模型」解耦已經發生——真正該問的是「我的 host 可靠嗎」，不是「我的工具有多貴」。
