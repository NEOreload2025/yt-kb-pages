1

建立知識庫：YT-KB Pipeline

核心概念

每支影片產出一個靜態 HTML，放進 videos/ 目錄，GitHub Pages 自動部署。知識庫 = 靜態檔案 + Git 版本控制，零資料庫、零維護成本。

輸入

YouTube 影片連結（需有 CC 字幕，語言不限）

產出

繁體中文摘要網頁 + 影片卡片 + 導航連結

關鍵規則：輸出語言固定繁體中文

無論影片字幕為英文、日文、簡體中文或其他語言，AI 產出的所有文字內容（摘要、重點、代碼註解、說明文件）統一使用繁體中文。這是知識庫語言一致性的核心規範，避免未來檢索時出現多語言混雜。

2

Origin 欄位：來源可追溯

每個重點卡片都標註 origin 來源，三種類型：

self 創作者親自說的、演示的內容
agent AI 根據上下文推論、補充、整理的內容
clipped 直接引用字幕逐字稿片段

這樣未來回頭看，能立刻分辨「這是影片原話」還是「AI 補充的」，建立信任鏈。

3

讀書筆記庫：雙向連結

同步建立 Obsidian 筆記

每支影片產出網頁的同時，也在本地 Obsidian Vault 建立對應筆記：

  • Frontmatter：影片 ID、標題、日期、標籤、YouTube 連結
  • 內容：同步網頁摘要、重點、origin 標註
  • 雙向連結：[[YT-KB]] ↔ [[Obsidian 實戰]] 互相引用
關鍵：Obsidian 是「可寫、可查、可被 AI 讀取」的本地知識庫；YT-KB 網頁是「可分享、可公開、可被搜尋引擎收錄」的公開面。兩者互補，不是替代。
4

Pipeline 自動化：從字幕到網頁

1. 抓取字幕

yt-dlp / YouTube API 抓取 CC 字幕（vtt/srt），語言不限

2. AI 摘要 + 結構化

Prompt 內建「輸出繁體中文」規則，產出 Markdown 結構

3. 注入模板產出 HTML

共用 CSS/JS 模板 + 視頻卡片 + 導航自動生成

4. Git Push → GitHub Pages

自動部署，零伺服器維護

把影片變成可檢索、可引用、可分享的知識資產

不只是看完忘記，而是每一分鐘的洞見都能在未來被 AI、被自己、被團隊找到、理解、復用。
